# AGA — AI Growth Animal

AGA는 기존 Windows AI-PET의 핵심 개체 상태를 모바일/태블릿에서 이어서 돌볼 수 있도록 만드는 **PWA Companion** 프로젝트입니다.

## 방향

- Windows AI-PET: PET의 집(Home). 바탕화면 이동, 로컬 파일 도구, Python 처리 엔진.
- AGA PWA: PET을 데리고 다니는 모바일 몸체. 터치, 대화, 가르치기, 성장 확인.
- 공통 상태 규격: `PET Portable State v1` JSON.
- 원칙: 같은 PET을 새로 복제하는 것이 아니라, 같은 개체의 상태를 옮기고 이어 키웁니다.
- 기본은 로컬 저장이며, 서버/호텔 동기화는 후속 단계에서 추가합니다.

## v0.1 목표

1. 설치 가능한 PWA
2. 오프라인 실행
3. 모바일 터치 돌봄
4. 간단한 대화/가르치기
5. IndexedDB 로컬 저장
6. PET Portable State JSON 가져오기/내보내기
7. 향후 Windows판과 연결할 공통 스키마 고정

## 개발 원칙

- 외부 CDN 없이 실행 가능
- 개인정보/기억은 기본적으로 기기 로컬 보관
- 사용자가 명시적으로 내보낼 때만 JSON 파일 생성
- 기능 권한은 향후 능력별로 분리
- 오프라인 시간을 방치/벌점으로 처리하지 않음

## v0.2 데이터 안정화

- IndexedDB 저장 위치/사이트 표시
- Storage API를 이용한 영구 저장 보호 요청
- 브라우저 저장공간 사용량 표시
- 마지막 저장 시각 및 PET JSON 크기 표시
- JSON 수동 백업/복원
- 저장할 때 직전 상태를 로컬 복구 지점으로 자동 보관
- 직전 로컬 상태 되돌리기
- GitHub에는 PET 데이터가 저장되지 않음

## v0.3 터치 감각 시스템

- 터치 부위 구분: 머리 / 귀 / 몸 / 꼬리
- 접촉 방식 구분: 톡 누르기 / 오래 손 얹기 / 천천히 쓰다듬기 / 빠르게 쓰다듬기
- 이동 방향과 속도 측정
- 부위별 접촉 경험과 친숙도 누적
- 가장 익숙한 접촉 부위를 감각 기억으로 표시
- 감정 변화가 터치 종류에 따라 다르게 반영
- 표정/몸짓/꼬리 애니메이션 반응
- 지원 기기에서 가벼운 진동 피드백
- 감각 정보도 PET Portable State에 포함

현재 단계: **AGA v0.3 터치 감각·반응**




## v0.4 Compact Companion UI

- 기본 화면은 PET 중심으로 단순화
- 큰 카드/상시 정보 패널 제거
- 돌보기·가르치기·기억·데이터는 하단 시트로 숨김
- PET 이름을 누르거나 중앙 ⌃ 버튼으로 시트 열기
- 하단의 ♡ / ✦ 버튼으로 빠른 돌봄과 놀이
- 마지막으로 사용한 기능 탭은 기억하되, 앱 시작 시에는 항상 PET 화면부터 표시
- 모바일/태블릿은 한 손 조작, Windows PWA는 작은 컴패니언 느낌을 목표로 함

현재 단계: **AGA v0.4 Compact Companion UI**
